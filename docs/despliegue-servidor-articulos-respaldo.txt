7. RESTAURACION DE BASES DE DATOS
============================================================

Validar nombres logicos:

/opt/mssql-tools/bin/sqlcmd -S 127.0.0.1,1466 -U SA -P '<SQL_SA_PASSWORD>' -Q "RESTORE FILELISTONLY FROM DISK = N'/var/opt/mssql/backup/TesisDW_Extensible.bak';"

Nombres logicos encontrados:

- TesisDB_Extensible
- TesisDB_Extensible_log

DW:
- TesisDW_Extensible
- TesisDW_Extensible_log

Restaurar OLTP:

/opt/mssql-tools/bin/sqlcmd -S 127.0.0.1,1466 -U SA -P '<SQL_SA_PASSWORD>' -Q "RESTORE DATABASE [TesisDB_Extensible] FROM DISK = N'/var/opt/mssql/backup/TesisDB_Extensible.bak' WITH MOVE N'TesisDB_Extensible' TO N'/var/opt/mssql/data/TesisDB_Extensible.mdf', MOVE N'TesisDB_Extensible_log' TO N'/var/opt/mssql/data/TesisDB_Extensible_log.ldf', REPLACE, RECOVERY, STATS = 10;"

Restaurar DW:

/opt/mssql-tools/bin/sqlcmd -S 127.0.0.1,1466 -U SA -P '<SQL_SA_PASSWORD>' -Q "RESTORE DATABASE [TesisDW_Extensible] FROM DISK = N'/var/opt/mssql/backup/TesisDW_Extensible.bak' WITH MOVE N'TesisDW_Extensible' TO N'/var/opt/mssql/data/TesisDW_Extensible.mdf', MOVE N'TesisDW_Extensible_log' TO N'/var/opt/mssql/data/TesisDW_Extensible_log.ldf', REPLACE, RECOVERY, STATS = 10;"

Verificar bases:

/opt/mssql-tools/bin/sqlcmd -S 127.0.0.1,1466 -U SA -P '<SQL_SA_PASSWORD>' -Q "SELECT name FROM sys.databases ORDER BY name;"

Verificar tablas:

/opt/mssql-tools/bin/sqlcmd -S 127.0.0.1,1466 -U SA -P '<SQL_SA_PASSWORD>' -d TesisDB_Extensible -Q "SELECT COUNT(*) AS TablesCount FROM sys.tables;"

/opt/mssql-tools/bin/sqlcmd -S 127.0.0.1,1466 -U SA -P '<SQL_SA_PASSWORD>' -d TesisDW_Extensible -Q "SELECT COUNT(*) AS TablesCount FROM sys.tables;"

- TesisDW_Extensible: 34 tablas.
